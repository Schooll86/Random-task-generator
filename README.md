# Random-task-generator

Простой генератор случайных задач с историей и фильтрацией.

## Автор
Обучающийся

## Описание
Приложение для генерации случайных задач из предопределённого списка. Позволяет:
* Генерировать случайные задачи по нажатию кнопки.
* Фильтровать историю задач по категориям (учёба, спорт, работа).
* Добавлять новые задачи в список.
* Сохранять историю всех сгенерированных задач.
* Очищать историю.

## Функциональность
* **Генерация задач:** кнопка «Сгенерировать задачу» выбирает случайную задачу из списка и отображает её.
* **История:** все сгенерированные задачи сохраняются с меткой времени и категорией.
* **Фильтрация:** возможность отображать историю только по выбранной категории.
* **Добавление задач:** пользователь может добавлять новые задачи с указанием категории.
* **Сохранение данных:** история и список задач сохраняются в JSON‑файлах между запусками.

## Использование
1. Запустите приложение: `python main.py`.
2. Нажмите кнопку **«Сгенерировать задачу»** — появится случайная задача.
3. Смотрите историю в списке ниже.
4. Используйте **фильтр** для отображения задач определённой категории.
5. Нажмите **«Добавить новую задачу»**, чтобы расширить список задач.
6. Нажмите **«Очистить историю»**, чтобы удалить все записи.
